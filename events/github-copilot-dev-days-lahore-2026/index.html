GitHub Copilot Dev Days Lahore

A hands-on, demo-driven day on AI-assisted development with GitHub Copilot, part of GitHub's global Copilot Dev Days series, hosted by CNSPK organisers.

About this event

The Lahore edition of GitHub Copilot Dev Days, a global series of community-led events. Hosted by Farhan Ashraf, Haroon Sohail, and Taskeen Fatima. The call for speakers required every session to include a live demo and real GitHub workflows, and rejected slide-only talks and product pitches.
