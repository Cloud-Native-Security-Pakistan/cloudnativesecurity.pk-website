03Contribute

How to contribute

The website is the easiest place to start. Pages are generated from JSON files in data/, so most fixes are a few lines of text.

  • Add a missing speaker, photo, or slide link to an event in data/events.json. Include a public source.
  • Fix a typo or broken link anywhere on the site.
  • Improve accessibility or performance. Run npm run check before opening the pull request.

Read CONTRIBUTING.md (opens in a new tab) first. Maintainers review pull requests, and changes ship to the live site when they are merged.
