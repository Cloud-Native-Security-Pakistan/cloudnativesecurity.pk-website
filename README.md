# cloudnativesecurity.pk

Website of **Cloud Native Security Pakistan (CNSPK)**, a volunteer-run, not-for-profit community for cloud-native security, open source, Kubernetes, DevSecOps, and AI security.

Live: https://cloudnativesecurity.pk

## How the site works

- **Content** lives in `data/*.json`: events, partners, projects, organisers, and organisation facts. Every fact carries a public source.
- **Pages** are generated by a small TypeScript build in `tools/site/` that runs directly on Node 24 with no runtime dependencies. Output is static HTML committed to the repo root.
- **Hosting** is GitHub Pages. Pushing to `main` deploys. The deploy job refuses to publish if the committed pages are out of date with `data/`.
- **No framework, no backend.** Pages work without JavaScript; `js/site.js` adds the mobile menu, archive filters, and email-composing forms.

```bash
npm ci
npm run build              # regenerate pages
node tools/site/serve.ts   # preview at http://localhost:4321/
npm run check              # typecheck + stale-page check + tests
```
