Call for proposals

Speak at CNSPK

We want talks built on real work: a demo that runs, a production lesson, or a contribution you shipped. First-time speakers are encouraged to apply.

Propose a talk →Past speakers →

01Guidance

What we look for

These criteria come from CNSPK's own calls for speakers for GitHub Copilot Dev Days Lahore (opens in a new tab) and Open Source Connect Pakistan (opens in a new tab).

  • A live demo or real artefact. Show the cluster, the pipeline, the pull request.
  • A real use case. Production experience, a project you maintain, or a problem you solved.
  • Takeaways people can act on. Attendees should be able to try something the next week.
  • No sales pitches. Sessions that mainly promote a commercial product or service are not accepted.
  • Clear audience level. Say whether the talk is for beginners, intermediate, or advanced attendees.

02Formats and topics

Formats and topics

10–15 min

Lightning talk

One idea, one demo. A good first talk.

20–30 min

Talk

A full story: problem, approach, demo, lessons.

45–60 min

Workshop

Hands-on. Attendees bring laptops and follow along.

Topics we cover

  • Cloud-native security and DevSecOps
  • Kubernetes and container security
  • Software supply-chain security
  • Open-source contribution and maintainership
  • Platform engineering and developer experience
  • AI security and open-source AI infrastructure
  • Observability, reliability, and incident stories
  • Careers into the global open-source ecosystem

03Process

How selection works

  1. 01

    Event calls

    Larger events open a call on Sessionize with a fixed deadline. It is announced in the community channels.

    Channels →
  2. 02

    Open proposals

    Between calls, send a proposal using the form below. Organisers match it to an upcoming meetup.

    Proposal form →
  3. 03

    Review and rehearsal

    Organisers reply by email. Accepted speakers can ask for a dry run and demo check before the event.
