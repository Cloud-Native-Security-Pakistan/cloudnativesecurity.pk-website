    Request an invite

03Volunteer

Help run the next event

Every CNSPK event is run by volunteers. Tell us what you would like to help with and the city you are in.

  • Event logisticsVenue walk-throughs, seating, power, and Wi-Fi checks before the day.
  • Registration and check-inRun the RSVP list and the front desk so the session starts on time.
  • Speaker liaisonHelp speakers scope talks, test demos, and rehearse.
  • Photography and recapsTake photos with consent and write the post-event record for this site.
  • DesignEvent posters and social graphics using the brand kit.
  • Website and dataKeep event records complete and fix pages through pull requests.

05Conduct

Code of conduct

The code of conduct applies at every CNSPK event and in every CNSPK channel, online and in person. It sets out expected behaviour, what is not acceptable, and how reports are handled.

To report a concern, email conduct@cloudnativesecurity.pk or speak to any organiser at the event.
